# Dokumentation

Die Dokumentation ist nach Zielgruppen geordnet. Wer CodePath zum ersten Mal einsetzt, beginnt mit dem Schnellstart in der [README](../README.md) und liest danach das Handbuch für die eigene Rolle.

## ◼ Handbücher

| Dokument | Für | Inhalt |
|---|---|---|
| [Handbuch für Lehrkräfte](lehrkraefte.md) | Lehrkräfte | Kurs anlegen, Klasse beitreten lassen, Module freischalten, Unterricht begleiten, Abgaben bewerten, Bestätigungen ausstellen, Inhalte bearbeiten |
| [Aufgabentypen](aufgabentypen.md) | Lehrkräfte, Autorinnen und Autoren | Alle 15 Typen: wofür sie sich eignen, wie bewertet wird, Standardregeln |
| [Betriebshandbuch](betrieb.md) | IT-Betreuung | Installation, Konfiguration, HTTPS, Backup und Wiederherstellung, Update, Code-Runner, Fehlersuche |
| [Sicherheit und Datenschutz](sicherheit.md) | Schulleitung, Datenschutz, IT | Welche Daten anfallen, wie sie geschützt und gelöscht werden, Sicherheitsmodell |
| [Entwicklerhandbuch](entwicklung.md) | Entwicklung | Architektur, lokale Umgebung, Tests, neue Aufgabentypen und Szenarien |
